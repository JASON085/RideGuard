# Security Policy

## Official Distribution

Official RideGuard / 白牌守路通 releases are distributed only through:

https://github.com/JASON085/RideGuard/releases

Please download RideGuard APK files only from the official GitHub
repository.

## Modified APKs

Modified, repackaged, or redistributed APK files are not official
RideGuard releases and are not supported.

## Update Security

RideGuard official application updates are distributed through GitHub
Releases and may include integrity, version, and digital signature
verification.

## Security Reports

If you discover a security issue, please avoid publishing sensitive
technical details before the issue has been reviewed.
