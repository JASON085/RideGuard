## 🛵 關於白牌守路通

**白牌守路通 RideGuard** 是專為白牌機車騎士設計的 Android 道路導航與道路狀況輔助應用程式。

除了基本路線規劃之外，RideGuard 著重於沿途道路狀況與通行風險資訊，例如：

- 道路封閉
- 交通管制
- 道路災害
- 山崩或道路中斷
- 交通事故
- 路線通行狀態

並以白牌機車的道路通行條件作為路線規劃的重要依據。

本 Repository 為 **RideGuard 官方 Binary Distribution Repository**。

## 🔄 Automatic Updates

RideGuard 支援透過官方 GitHub Releases：

- 自動檢查新版
- 下載官方 APK
- 版本驗證
- SHA-256 完整性驗證
- Release Manifest 數位簽章驗證
- APK 身分與簽章驗證

更新流程會優先避免干擾正在進行中的導航與騎乘行程。
