# 白牌守路通 / RideGuard

**白牌守路通 RideGuard** 是為白牌機車騎士設計的 Android 公路導航與道路狀況輔助應用程式。

本 Repository 為 **RideGuard 官方 APK 發佈與自動更新來源**。

## Download

正式版本請由本 Repository 的 **Releases** 頁面下載：

https://github.com/JASON085/RideGuard/releases

## Automatic Updates

RideGuard 支援透過官方 GitHub Releases 自動檢查及下載新版 APK。

正式更新檔案會經過版本、完整性及 APK 簽章驗證後才進行安裝。

## Source Code

RideGuard 為 proprietary software。

本 Repository 不公開 Android / Kotlin 原始碼，也不包含 Android Studio Project 或其他開發用 Source。

本 Repository 僅用於：

- 官方 APK 發佈
- Release Notes
- 應用程式版本資訊
- RideGuard 自動更新

## Security

請只從本 Repository 的官方 Releases 下載 RideGuard。

第三方修改、重新封裝或重新散布的 APK 並非官方 RideGuard 版本。
