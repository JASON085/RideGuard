## 🛵 關於白牌守路通

**白牌守路通（RideGuard）** 是一款專為台灣白牌機車騎士設計的導航與道路安全輔助 App。不同於一般導航軟體只著重「怎麼到目的地」，RideGuard 更重視「這條路現在能不能安全、合法地騎過去」。

App 會依白牌機車可通行的道路進行路線規劃，避開高速公路及禁止白牌機車行駛的快速道路，並持續監看規劃路線上的 **封路、交通管制、道路事故、山崩及其他可能影響通行的道路事件**，在騎士抵達前提供提醒與道路判斷。

導航過程中，RideGuard 會持續比對 GPS 位置與目前路線；若發生明顯偏航，可由目前位置自動重新規劃路線，避免仍顯示已經失效的舊路線與轉彎指示。同時整合 GPS、移動狀態判斷、車頭方向地圖與前景導航機制，讓長途騎乘、山區道路及複雜路況下的導航更加實用。

**核心功能包含：**

* 🛵 白牌機車專用路線規劃
* 🚫 避開高速公路與禁止白牌通行道路
* 🚧 封路、交通管制、事故與道路異常預警
* 🗺️ 路線沿途道路狀況監看
* 🔄 偏離路線自動重新規劃
* 🧭 車頭方向 Heading-Up 地圖
* 📍 GPS 與移動狀態輔助判斷
* 🔆 導航期間保持螢幕與前景導航運作
* 💾 本機路線、設定與資料保存
* 🔐 GitHub Secure Auto Update 安全更新機制

RideGuard 的目標不是取代所有導航 App，而是成為 **白牌機車騎士在出發前與騎乘途中，多一層道路通行判斷與安全保障的工具。**

## 🔄 Automatic Updates

RideGuard 支援透過官方 GitHub Releases：

- 自動檢查新版
- 下載官方 APK
- 版本驗證
- SHA-256 完整性驗證
- Release Manifest 數位簽章驗證
- APK 身分與簽章驗證

更新流程會優先避免干擾正在進行中的導航與騎乘行程。
